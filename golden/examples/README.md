# Examples Directory

This directory contains **example implementations**, usage snippets, and reference code that illustrate how to use the system correctly.

## Purpose
- Provide concrete, runnable examples of integrating with contracts.
- Demonstrate best‑practice usage of adapters, APIs, and data shapes.
- Serve as a living documentation for developers and integrators.

## Structure
- `api/` – Example API clients and requests.
- `adapters/` – Example adapter implementations for third‑party services.
- `data/` – Example payloads and schemas.
- `tests/` – Example contract‑test implementations.

## Rules
1. **Examples must be correct**: They should compile/run and follow the golden rules.
2. **Examples must be up‑to‑date**: When contracts change, update the corresponding examples.
3. **Examples are not production code**: They are illustrative and may omit error‑handling for clarity.

## Usage
- Copy and adapt examples into your integration code.
- Use examples as a reference when writing new adapters.
- Run examples to verify your environment setup.
